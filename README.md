# Island

Dynamic Island для Windows 10/11.

## Возможности

- Музыкальный плеер
- Уведомления и звонки
- Режим «Не беспокоить»
- Буфер обмена
- Полка для файлов
- Таймер
- Заметки
- Громкость
- Быстрый поиск и калькулятор (Alt+Space)
- Пипетка
- Погода
- Темы: тёмная, серая, светлая
- Русский и английский язык
- Свои вкладки и кнопки
- Системный мониторинг: CPU, RAM, GPU, температура и скорость сети
- Перевод выделенного текста (Ctrl+Alt+T)
- Автообновления из GitHub Releases

Скрыть или показать: Ctrl+Alt+I. Настройки открываются кнопкой с шестерёнкой в островке или из меню в трее.

## Новые функции

**Система.** Одна вкладка с показателями, без дополнительных панелей. В настройках «Система» можно отключить мониторинг, скрыть показатели и изменить порядок. В «Показателях» можно добавить GPU, температуру или скорость загрузки в верхний ряд колец. Подробные датчики опрашиваются раз в две секунды, только пока их видно. Скорость сети показывает самый активный адаптер, чтобы не складывать повторно трафик VPN; это текущая передача данных, а не проверка пропускной способности.

GPU использует счётчики Windows WDDM. Температура берётся из NVIDIA NVML или датчиков запущенного LibreHardwareMonitor / OpenHardwareMonitor. Показывается самый горячий из доступных CPU/GPU-датчиков; источник виден при наведении. Если драйвер или датчик не предоставляет данные, будет прочерк. Island не устанавливает драйверы и не требует прав администратора.

**Переводчик.** Выделите текст в другом приложении и нажмите Ctrl+Alt+T. Перевод появится внутри островка, его можно скопировать. Используется системный интерфейс доступности UI Automation. Если приложение не отдаёт выделение, скопируйте его и нажмите «Перевести буфер». Отдельную кнопку переводчика можно включить и переставить в настройках «Кнопки».

Поддерживаются русский и английский: автоматическое направление RU ↔ EN либо выбранный язык результата. До 4000 символов за один запрос пользователя. Используется Google Translate через веб-интерфейс перевода, без ключа Cloud API. Это не официальный Cloud API: сервис может менять интерфейс или ограничивать запросы. Выделенная фраза передаётся целиком, без разрезания на короткие фрагменты. Нужен интернет. Автоматический перевод после выделения выключен по умолчанию и включается в настройках «Переводчик». Перевод выделений не отслеживает клавиатурное выделение автоматически; для него используйте горячую клавишу. Поля паролей не читаются, содержимое буфера не заменяется до нажатия «Скопировать».

**Обновления.** В настройках «Обновления» можно отключить автоматическую проверку. При включении проверка выполняется через 15 секунд после запуска и каждые 6 часов. Релиз загружается в фоне, проверяется по SHA-256 из GitHub и версии сборки. Для установки нажмите уведомление или «Перезапустить и обновить» в настройках. Предыдущий EXE сохраняется рядом как `.previous`; при ошибке замены он восстанавливается. Для обновления нужен доступ на запись в папку приложения.

Старые настройки, заметки и буфер сохраняются. При переходе с 1.1.0 нужно один раз скачать 1.2.0 вручную: старый EXE ещё не содержит обновлятор.

## Установка

Скачайте `Island.exe` со страницы [Releases](../../releases) и запустите. Установка не нужна, нужен .NET Framework 4.8 (в Windows 10/11 уже есть).

Windows SmartScreen может предупредить о неизвестном издателе. Нажмите «Подробнее», потом «Выполнить в любом случае».

## Сборка

Visual Studio не нужна, используется компилятор из .NET Framework:

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Готовый файл появится в `bin\Island.exe`.

Для проверки переводчика в отдельных тестовых окнах (нужны интерактивный рабочий стол и интернет): `powershell -ExecutionPolicy Bypass -File test-selection.ps1`. Проверяются выборка текста при фокусе на нетекстовом элементе, сообщение горячей клавиши и событие мыши, настоящий запрос перевода и видимость карточки после полноэкранного скрытия. В `obj` сохраняются отчёты и изображения карточки. Проверка не заменяет ручной проверки в конкретном браузере.

Проверки, включая реальную замену и перезапуск тестового EXE в отдельной папке:

```
powershell -ExecutionPolicy Bypass -File test.ps1
```

## Данные

Настройки, история буфера и заметки лежат в `%APPDATA%\Island`. В сеть уходят замер пинга (cp.cloudflare.com), запрос погоды (город по IP через ip-api.com или из настроек, прогноз с met.no), проверка и загрузка обновлений (GitHub), текст для перевода (translate.googleapis.com). Погоду, автообновления и переводчик можно выключить. Текст отправляется в Google Translate только по команде пользователя либо при явно включённом переводе выделения. В журнал переводимый текст не записывается. Загруженные обновления временно хранятся в `%LOCALAPPDATA%\Island\updates`.
